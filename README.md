# Focus English Lab

2026년 1월 21일 이후 공개된 영어 능력시험의 과제 설명을 참고한 독립 연습용 웹 앱입니다. 모든 문제는 이 프로젝트를 위해 새로 작성했으며 공식·기출 문항이나 공식 채점 엔진을 포함하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버를 켜면 Kokoro 모델도 서버에서 한 번만 준비됩니다. 생성된 WAV는 `.cache/tts/`에 저장되며 같은 문장과 화자는 다시 합성하지 않습니다. 첫 모델 다운로드와 첫 문장 생성은 백그라운드에서 진행되어 시험 시작을 차단하지 않습니다.

이 작업 폴더에는 모델이 `.cache/models/`에 미리 준비되어 있어 평소 실행 중에는 다운로드하지 않습니다. 모델 캐시를 직접 지운 경우에만 `npm run tts:download`를 한 번 실행하세요.

브라우저에서 표시되는 로컬 주소를 여세요. Speaking 연습은 마이크 권한이 필요합니다.

## 웹 버전과 휴대용 시험 데이터

GitHub Pages 배포 설정이 `.github/workflows/pages.yml`에 포함되어 있습니다. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 한 번 지정하면 `main` 브랜치가 갱신될 때 `https://aoml3245.github.io/focus-english-lab/`에 자동 배포됩니다.

홈의 **시험 데이터** 화면에서는 다음 작업을 할 수 있습니다.

- 현재 또는 기본 1,360문항을 `.felpack.json`으로 내려받기
- 휴대폰·태블릿·다른 컴퓨터에서 같은 파일을 선택해 문제은행으로 사용하기
- 가져온 파일을 해제하고 기본 문제은행으로 복원하기

파일은 브라우저 안에서만 읽고 외부 서버에 업로드하지 않습니다. 웹 버전의 Listening·Speaking도 브라우저 안에서 Kokoro 82M q8 모델을 실행하며, 처음 사용할 때만 약 90MB급 모델 데이터를 내려받아 브라우저 캐시에 저장합니다. Ollama Writing/Reading 보조 기능은 로컬 실행에서만 사용할 수 있습니다. 학습 기록과 내가 만든 단어장은 시험 데이터에 포함되지 않으며 현재 기기의 브라우저 저장소에 남습니다.

시험 데이터 화면의 원형 **?** 버튼을 누르면 `.felpack.json` 최상위 구조, 8개 문항 유형별 필수 필드, 객관식 정답 번호 규칙을 볼 수 있고 전체 유형이 들어 있는 예제 파일도 내려받을 수 있습니다.

## 포함된 기능

- Reading → Listening → Writing → Speaking 순서
- 1,360개의 독창적인 문제은행과 매회 새로 구성되는 랜덤 세트
- `랜덤 전체 세트`: 객관식 문항마다 답을 제출한 즉시 정오답·정답·해설을 보여주고 피드백 중 타이머 정지
- `실전 모의시험`: 실제 시험처럼 진행 중에는 정답을 숨기고 전체 종료 후 결과와 해설 공개
- 섹션·유형별 집중 연습: Reading 3종, Listening 4종, Writing 3종, Speaking 2종을 각각 따로 선택하거나 섹션 전체 유형을 섞어 출제
- 83개 주제 묶음을 학술 지문·생활 안내·캠퍼스 대화·강의·이메일·토론·인터뷰 맥락으로 연결
- IELTS, Cambridge English, PTE Academic, Duolingo English Test의 공식 과제 설명에서 맥락 범주를 조사해 반영
- 환경·과학·공학·심리·경제·역사·예술·기술·보건·캠퍼스 행정 등 폭넓은 주제
- 문항별 타이머와 자동 이동
- Listening 이전 문항 복귀 제한
- ETS 공식 예시를 반영한 Writing 문장 구성: 5–8개의 섞인 단어·짧은 구 타일, 빈칸 슬롯, 일부 방해 타일
- 브라우저 TTS 오디오와 마이크 녹음
- Kokoro 82M 오픈소스 AI 음성, 대화 자동 배역, 미국식·영국식 음성 미리 듣기와 기본 음성 저장
- 시험 시작 전 TTS 엔진·선택 화자 워밍업, 테스트 문장과 첫 실제 음성 선행 합성, 실패 시 세션 단위 시스템 음성 대체
- `localStorage` 자동 저장·이어하기와 최근 50회 학습 기록
- 객관식 기반 연습 추정 결과
- 완료한 시험의 전체 문항·당시 답안·정답·해설 복습
- 시험별 랜덤 후보 포함/제외 선택: 제외한 세트의 문항은 기록을 보존한 채 이후 전체·섹션 랜덤 출제에서 제외
- 문제은행 문맥 어휘 약 2,000개와 공개 사전에서 품질 조건을 통과한 어휘를 합친 29,976개 단어장: 뜻·영영 정의·발음·품사·CEFR·동의어(최대 3개)·예문·한국어 해석
- 문항 빈도와 B2–C2 난이도를 결합한 프로젝트 자체 학술 핵심 표시
- 영어/한국어/동의어 통합 검색, 난이도·주제·학술 핵심 필터, 학술 우선·빈도·알파벳 정렬, 브라우저 저장 단어
- Reading 지문 단어 즉시 조회, 문장 드래그 해석, 문항별 정답·해설 펼쳐 보기
- 로컬 Ollama LLM을 이용한 문맥별 한국어 뜻·유의어 3개·예문 해석 자동 정리
- 단어장 표제어·예문 음성 재생: 음성 설정에서 선택한 Kokoro AI 음성 또는 기기 기본 음성 사용
- 단어 시험: 영어→뜻 입력, 뜻→영단어 철자 회상, 동의어 객관식과 문항별 즉시 정답 확인
- 문장 미니게임: 문제은행 문맥 예문으로 영어→한국어 해석과 한국어→영어 영작을 번갈아 연습하고 정답 예시 즉시 확인
- 선택적 로컬 LLM 문장 평가: 의미 보존·문법·어휘·자연스러움 점검, 교정 설명과 개선 답안 제공
- Qwen 3.5 9B 로컬 Writing 코치: ETS 기준 0–5 연습 추정, 강점·기준별 진단·문장 교정·수정 계획·개선본·후속 질문

## 범위

전체 연습은 유형 비율을 유지한 55문항, 섹션 연습은 11–16문항을 문제은행에서 무작위로 선택합니다. 정식 다단계 적응형 출제와 서버 계정 동기화는 포함하지 않습니다. Writing 코치의 점수는 학습을 위한 로컬 LLM 추정치이며 ETS 공식 점수가 아닙니다. 모든 문제는 공식 형식과 맥락 범주만 참고해 새로 작성했으며 어떤 시험의 공식·기출 문항도 아닙니다. 조사 근거는 [`research-sources.md`](./research-sources.md)에 정리했습니다.

단어장 생성 결과는 `public/vocabulary.json`에 포함되어 있어 실행 중 외부 번역 서비스가 필요하지 않습니다. 기존 문제은행 어휘는 원문 예문을 유지하며, 추가 어휘는 사전 정의를 확인하는 학습 문장을 사용합니다. 제3자 어휘 데이터의 출처·라이선스와 재생성 방법은 [`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md)와 [`DATA_LICENSE.md`](./DATA_LICENSE.md)를 참고하세요.

AI 음성은 처음 사용할 때 Kokoro q8 모델(약 90MB)을 Hugging Face에서 내려받아 브라우저의 `transformers-cache`에 저장하고 이후 브라우저 안에서 실행됩니다. 음성 설정과 시험 시작 전 확인 화면에는 실제 파일별 다운로드 퍼센트, 받은 용량/전체 용량, 파일명과 캐시 저장 여부가 표시됩니다. 모델 로딩이나 재생이 불가능한 환경에서는 자동으로 기기의 영어 음성 합성 기능을 사용합니다.

모의시험·섹션 연습·이어하기는 모두 시작 전 확인 화면을 거칩니다. 이 화면에서 선택한 TTS 엔진을 초기화하고 필요한 화자를 워밍업하며, 테스트 문장과 선택 세트의 첫 음성 문항을 미리 합성합니다. 준비가 끝나기 전에는 시험 시작 버튼이 비활성화되고, 준비 완료 후에는 짧은 음성 테스트를 직접 들을 수 있습니다.

읽기 도우미는 기본적으로 `http://127.0.0.1:11434`에서 실행 중인 Ollama의 `translategemma:latest`를 사용합니다. 로컬 모델이 꺼져 있어도 기존 어휘는 내장 사전 뜻으로 즉시 확인할 수 있습니다. 지문에서 `내 단어장에 넣기`로 저장한 단어와 생성 결과는 이 브라우저에만 보관되며, 단어장 화면의 `내가 만든 단어장` 필터에서 다시 볼 수 있습니다.

Writing 코치는 같은 Ollama 서버의 `qwen3.5:9b`를 기본으로 사용합니다. 16GB Apple Silicon 환경에서 품질과 메모리 사용량의 균형을 고려한 선택이며, 설치 명령은 `ollama pull qwen3.5:9b`입니다. 평가·대화 중에는 시험 타이머가 자동으로 멈추고 결과는 문항별로 브라우저에 저장됩니다.
